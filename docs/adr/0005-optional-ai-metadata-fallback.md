# Optional AI Metadata with Deterministic Fallback

Requiring an active local LLM (such as Ollama) or a paid cloud API key would prevent users with limited hardware or zero budget from using the software. We decided that the AI Router is strictly an optional creative enhancement for titles, descriptions, and tags, with a zero-AI deterministic templating fallback enabled by default. This ensures the entire video editing and montage pipeline functions 100% offline out-of-the-box.

# LazyCut
ครีเอเตอร์สายโซโล่ (Solo YouTuber, Streamer) และเกมเมอร์ที่ทำงานประจำหรือมีเวลาจำกัด มักประสบปัญหาไม่มีเวลาตัดต่อคลิปไฮไลต์ด้วยตัวเอง LazyCut จึงถูกออกแบบมาเพื่อเป็นเว็บแอปพลิเคชันแบบ Open-Source (Local-First) ที่ทำงานแบบกึ่งอัตโนมัติ (Semi-Automation) ช่วยเปลี่ยนไฟล์คลิปดิบในโฟลเดอร์ให้กลายเป็นวิดีโอไฮไลต์ที่พร้อมเผยแพร่

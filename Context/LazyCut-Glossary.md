# LazyCut Glossary

LazyCut เป็นสตูดิโอตัดไฮไลต์สำหรับสตรีมเมอร์และเกมเมอร์ นิยามนี้อัปเดตขอบเขตจากแผนเดิมให้ครอบคลุมทั้งไฟล์บันทึกสั้นและยาว

## Language

**Source Clip**

ไฟล์บันทึกการเล่นที่เป็นต้นทางในการตัดไฮไลต์ หนึ่งไฟล์อาจเป็นช็อตสั้นหรือการบันทึกยาวทั้งแมตช์ และอาจมีหลายเหตุการณ์

**Player Kill**

เหตุการณ์กำจัดที่เกมให้เครดิตแก่ผู้เล่นเจ้าของไฮไลต์ Headshot Kill เป็น Player Kill ที่เกิดจากการยิงศีรษะ

**Action Window**

ช่วงเวลาจาก Source Clip ที่ครอบคลุม Player Kill และภาพก่อนกับหลังเหตุการณ์ ช่วงเดียวอาจครอบคลุมหลาย kill ที่เกิดติดกัน

**Reel**

วิดีโอไฮไลต์ที่ประกอบจาก Action Window ที่เลือกและส่งออกเป็นไฟล์พร้อมอัปโหลด ความยาวและสัดส่วนภาพเป็นตัวเลือกอิสระจากกัน

**Duplicate Source Clip**

ไฟล์บันทึกการเล่นเดิมที่พบอีกครั้งหลังเปลี่ยนชื่อ ย้ายตำแหน่ง หรือคัดลอก การพบไฟล์เดิมอีกครั้งไม่ทำให้สถานะที่เคยตัดกลับเป็นงานใหม่

**Exported Action Window**

Action Window ที่รวมอยู่ใน Reel ซึ่งส่งออกสำเร็จแล้ว Source Clip หนึ่งไฟล์อาจมีทั้งช่วงที่ส่งออกแล้วและช่วงที่ยังใช้ต่อได้

**Reel Rating**

คะแนนล่าสุดของ Reel ที่ผู้ใช้เลือกจากสี่ระดับ ได้แก่ ดีมาก, ดี, แย่ และ แย่มาก แต่ละ Reel อาจยังไม่มีคะแนน

# ADR 0010 — งานตัดต่อเริ่มด้วยผู้ใช้และมีขอบเขตจำกัด

**สถานะ** ตกลงแล้วเมื่อ 18 พฤศจิกายน 2569

LazyCut เฝ้าโฟลเดอร์เพื่อทราบว่ามี Source Clip ใหม่ และรอให้ผู้ใช้กดเริ่มก่อนส่งงานประมวลผล เพื่อให้ผู้ใช้เลือกเวลาใช้ทรัพยากรเครื่อง ภายในการกดเริ่มหนึ่งครั้งให้กำหนดชุดไฟล์จากไฟล์ที่พร้อม ณ ขณะนั้น และจำกัดจำนวน Reel ตามที่ผู้ใช้กำหนด เพื่อให้งานมีขอบเขตที่จบได้แม้มีไฟล์ใหม่เข้ามา

ชุดไฟล์ตอนกดเริ่มกำหนดว่าไฟล์ใดเข้าเกณฑ์สำหรับงานนี้ ระบบทยอยตรวจตามที่จำเป็นและส่งออกทีละ Reel เมื่อครบจำนวนที่ขอให้หยุดวิเคราะห์ ไฟล์ในคิวที่ยังไม่ได้ตรวจ ไฟล์ที่เข้าทีหลัง และช่วงที่ยังไม่ได้ใช้เมื่อถึงเพดานจำนวน Reel คงอยู่สำหรับการกดเริ่มครั้งถัดไป ผู้ใช้สั่งนำ Action Window ที่เคยส่งออกมาทำซ้ำเองได้ เช่น ทำ Reel อีกสัดส่วน

จำนวนเริ่มต้นคือ 3 Reel ต่อครั้ง ผู้ใช้เปลี่ยนได้และเห็นเพดานเวลารวมจากจำนวน Reel คูณความยาวสูงสุดต่อ Reel หากการส่งออกล้มเหลว ให้หยุดงานและเก็บเฉพาะ Reel ที่ส่งออกสำเร็จไว้ ช่วงของ Reel ที่ล้มเหลวและช่วงที่เหลือยังพร้อมสำหรับงานถัดไป

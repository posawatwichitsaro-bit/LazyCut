# LazyCut รุ่นแรก — ขอบเขตและความคืบหน้า ณ 18 พฤศจิกายน 2569

ผู้เล่นอัด VALORANT ไว้ในโฟลเดอร์ ตั้งรูปแบบ กดเริ่มหนึ่งครั้ง แล้วรับไฟล์ MP4 พร้อมอัปโหลด เกณฑ์คุณภาพคือผู้ใช้ดู Reel จริงแล้วตัดสินว่าจังหวะที่เลือกและการตัดต่อถึงระดับ Outplayed Supercut

| ส่วนงาน | ขอบเขตรุ่นแรก | สถานะปัจจุบัน |
| --- | --- | --- |
| รับไฟล์ | รับคลิปสั้นและไฟล์ทั้งแมตช์ เริ่มจากไฟล์พร้อมตอนกดปุ่ม ทยอยทำจนได้จำนวน Reel ที่ขอ | พัฒนาแล้ว ทดสอบคิวผ่าน API และการหยุดก่อนอ่านไฟล์ถัดไป |
| เลือก Kill | รองรับ HUD หลายภาษา เลือกเฉพาะ Kill ของเจ้าของคลิป ข้ามเหตุการณ์คลุมเครือและจบได้เมื่อไม่มี Kill | ตัวตรวจยังพึ่งแม่แบบคำว่า “ฉัน” รอตรวจด้วยคลิปจริงหลายภาษา ทั้งตอนเล่นเองและดูเพื่อนเล่น |
| ตัดและส่งออก | เลือกสั้นหรือยาวแยกจาก 16:9 หรือ 9:16 แนวตั้งแสดงภาพกลางและ killfeed ตั้งจำนวน Reel และเพดานเวลารวม | เรนเดอร์ MP4 ใน Docker แล้ว ค่าเริ่มต้น 3 Reel คลิปสั้นสูงสุด 180 วินาที ช่องเวลารับวินาที คลิปยาวมีเพดานปัจจุบัน 900 วินาที |
| ทำงานต่อ | จำไฟล์จากเนื้อหา บันทึก Kill และช่วงต้นทางหลัง Export สำเร็จ เก็บช็อตที่เกินเพดานสำหรับรอบหน้า ช่วงต่อเนื่องใช้ภาพซ้ำได้สูงสุด 15 วินาทีและต้องมี Kill ใหม่ | ผ่านกรณีเปลี่ยนชื่อไฟล์ คำนวณช่วงทับ และจำลอง Reel ที่สองล้มเหลวแล้วทำต่อได้ ส่วน Export รุ่นเดิมไม่มีเวลาของ Kill สำหรับเติมประวัติย้อนหลัง |
| รีวิว | ดูผลงาน ให้หรือแก้คะแนน ดีมาก ดี แย่ แย่มาก เก็บยอดในเครื่อง | มีประวัติ Export และ exports/ratings.json ทดสอบแก้คะแนนและยอดนับแล้ว รอผู้ใช้ตัดสินคุณภาพผลงานจริง |

## หลักฐานการส่งมอบ

- ผลชุดทดสอบ Docker รอบล่าสุดตามรายงานประจำวัน ผ่าน 57 ข้อ ข้าม 1 ข้อเพราะไม่มีคลิป VALORANT จริง การทดสอบวิดีโอสังเคราะห์ยืนยันขั้นตอนการเรนเดอร์ ส่วนความแม่นยำในการระบุผู้เล่นยังรอตรวจ
- สาขา feat/folder-highlight-queue คอมมิต 78ecae3 อยู่ใน [PR #2](https://github.com/posawatwichitsaro-bit/LazyCut/pull/2) รอการรีวิว
- อัปเดต Studio ที่ 127.0.0.1 พอร์ต 8000 แล้ว ระบบ healthy และมีปุ่มคิวกับช่องคะแนน การทดสอบผ่านเบราว์เซอร์ใช้คอนเทนเนอร์แยกข้อมูลและวิดีโอจำลอง

## งานที่เหลือเพื่อปิดรุ่นแรก

1. ใช้คลิปจริงหลายภาษาทั้งสั้นและยาวที่รู้ว่าใครได้ Kill ตรวจทั้งช็อตที่เลือกผิดและช็อตที่ตกหล่น รวมช่วง spectate และคลิปไม่มี Kill แล้วปรับตัวตรวจ ชื่อผู้เล่นเป็นตัวช่วยตามเงื่อนไข หากพิสูจน์ว่าเพิ่มความแม่นยำจึงเพิ่มช่องและจำค่าในเครื่อง
2. ทดสอบผ่านหน้า Studio ตั้งแต่กดเริ่มจนเล่น MP4 และให้คะแนน ตรวจเพดานเวลา จังหวะก่อนและหลัง Kill การอ่าน killfeed บนมือถือ และเวลาประมวลผลไฟล์ทั้งแมตช์ ให้ผู้ใช้รีวิวคุณภาพเทียบเป้าหมาย Supercut
3. ผู้ดูแลพิจารณารวม PR #2 เมื่อพร้อม

## แผนภายหลัง

Local AI หรือ Cloud AI สำหรับตัดฉาก จัดจังหวะและเพิ่มเสียง รวมถึงโหมดค้นหาช็อตเด่นที่สุดโดยวิเคราะห์ทุกแมตช์ก่อนส่งออก เป็นงานต่อยอด รุ่นแรกสิ้นสุดที่ไฟล์พร้อมให้ผู้ใช้อัปโหลดเอง
